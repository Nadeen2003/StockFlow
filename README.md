# StockFlow

StockFlow is an inventory management system for organizing products and categories, tracking stock levels, and recording inventory movements.

## Project status

The project is currently a frontend built with HTML, CSS, and vanilla JavaScript. It uses sample data to preview the dashboard, products, categories, and transactions screens. Forms and search controls are visual previews; data is not saved yet.

## Current interface

- Dashboard overview with inventory summary cards, recent movements, and low-stock items
- Product catalog with category, stock, and price details
- Category overview
- Stock-in and stock-out transaction history
- Responsive layout and basic page navigation

## Built with

- HTML
- CSS
- Vanilla JavaScript

## Run locally

Open `index.html` in a browser. No installation or build tools are required.

## Planned development

StockFlow will grow step by step as a learning and portfolio project. Planned improvements include interactive product and category management, validation, stock transaction logic, and dashboard calculations. Backend technologies and a database will be introduced later as they are learned.
